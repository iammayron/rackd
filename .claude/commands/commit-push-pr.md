Commit and push the working changes for this repo.

Context (precomputed):

- Branch: !`git branch --show-current`
- Status: !`git status --short`
- Diff stat: !`git --no-stat diff --stat HEAD`

Steps:

1. Run the gate first:
   ```bash
   pnpm typecheck && pnpm test
   ```
   If it fails, stop and report — do not commit.
2. Stage all changes (`git add -A`).
3. Write a concise commit message in the repo's style: imperative subject ≤ ~70 chars; a short body only when the "why" isn't obvious. No "Generated by" footer.
4. Commit, then push. Default branch is `main` (remote `origin`). For non-trivial work, open a PR from a short-lived branch instead of pushing straight to `main`.
5. Report the commit hash and what was pushed.

$ARGUMENTS may contain a commit message or instructions — honor them.
