# /commit-push-pr — gate, commit, push

Commit and push the working changes for this repo.

Steps:

1. Inspect the working tree:
   ```bash
   git branch --show-current
   git status --short
   git --no-pager diff --stat HEAD
   ```
2. Run the gate first:
   ```bash
   pnpm typecheck && pnpm test
   ```
   If it fails, stop and report — do not commit.
3. Stage all changes (`git add -A`).
4. Write a concise commit message in the repo's style: imperative subject ≤ ~70 chars; a short body only when the "why" isn't obvious. No "Generated by" footer.
5. Commit, then push. Default branch is `main` (remote `origin`, github.com/iammayron/myfit). For non-trivial work, push a short-lived branch and open a PR rather than pushing straight to `main`.
6. Report the commit hash and what was pushed.

If the user passed a message or instructions with the command, honor them.
